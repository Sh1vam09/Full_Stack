npx create-next-app@latest my-portfolio

Would you like to use TypeScript? → Yes (Highly recommended for better coding tools, even if you are new to it).

Would you like to use ESLint? → Yes (Keeps your code clean).

Would you like to use App Router? (recommended) → YES (Crucial! This is the feature that makes nested/dynamic routing easy).
