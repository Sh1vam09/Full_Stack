# Experiment 2: Responsive Web Design with Tailwind CSS

## Description
This experiment demonstrates responsive web design using Tailwind CSS utility classes.

## Features
- Responsive grid layouts (1 column on mobile, 2 on tablet, 3 on desktop)
- Responsive flex layouts
- Responsive typography
- Responsive buttons and spacing

## Setup
```bash
npm install
npm run dev
```

## Tailwind CSS Breakpoints
- `sm`: 640px
- `md`: 768px
- `lg`: 1024px
- `xl`: 1280px
- `2xl`: 1536px
