# Experiment 9: SEO and Performance Optimization

## Description
This experiment demonstrates SEO optimization and performance improvements using next/head and next/image.

## Features
- Metadata management with next/head
- Image optimization with next/image
- Open Graph tags for social media
- Twitter cards
- Canonical URLs
- Lazy loading images
- Responsive images

## Setup
```bash
npm install
npm run dev
```

## SEO Features
- Custom page titles and descriptions
- Open Graph metadata
- Twitter card support
- Canonical URLs
- Proper heading hierarchy

## Performance Features
- Automatic image optimization
- Lazy loading
- Format optimization (WebP)
- Responsive images
- Code splitting

## Pages
- `/` - Home page with SEO and image examples
- `/about` - About page with custom metadata
- `/products` - Products page with optimized images
