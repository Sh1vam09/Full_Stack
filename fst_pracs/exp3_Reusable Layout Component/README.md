# Experiment 3: Reusable Layout Component

## Description
This experiment demonstrates creating a reusable Layout component for consistent UI across all pages.

## Features
- Reusable Layout component with header, main content, and footer
- Consistent navigation across pages
- Shared styling and structure
- Used in _app.tsx to wrap all pages

## Setup
```bash
npm install
npm run dev
```

## Pages
- `/` - Home page
- `/about` - About page
- `/contact` - Contact page

All pages use the same Layout component for consistency.
