# Experiment 1: Multi-Page App with Dynamic and Nested Routes

## Description
This experiment demonstrates Next.js routing system including:
- Static pages (about.tsx)
- Dynamic routes ([id].tsx)
- Nested routes (blog/[slug].tsx)

## Setup
```bash
npm install
npm run dev
```

## Routes
- `/` - Home page
- `/about` - Static about page
- `/products` - Products list
- `/products/[id]` - Dynamic product detail page
- `/blog` - Blog posts list
- `/blog/[slug]` - Nested dynamic blog post page
